# No tracked file names another implementation's internals.
#
# This crate is licensed MIT OR Apache-2.0, and that grant is one it can make only for code
# that derives from nothing licensed otherwise. The filesystems it reads and writes are
# implemented, in the kernel and in their reference tools, under the GPL. So a rule here is
# described in the format's own terms: the structures the format's documentation names, and
# what a tool or a kernel is observed to do. It is not described by the routine in another
# implementation that applies it.
#
# A name is not a copy, and a file free of them is not thereby clean. But a comment naming a
# routine reads as code derived from it, whether or not it is, and it points the next reader
# at that routine's source. That is the part a lexical gate can hold, and this is the gate.
#
#   ci/provenance.sh            check
#   ci/provenance.sh --list     print the rules without running them
#
# What it denies, anywhere in a tracked text file:
#
#   prefix   a lowercase identifier with one of these prefixes that this tree does not
#            itself define. `fat_type` is a field here and passes; a routine of another
#            implementation with the same prefix does not.
#   name     an identifier another implementation uses for one of its routines, without a
#            prefix to find it by. Denied even where this tree defines it.
#   path     a path into another implementation's source tree, or a link to one.
#   macro    another implementation's internal macro.
#
# What accounts for a hit:
#
#   format       a name the format's own documentation gives a structure. Those describe the
#                bytes, and every implementation of the format uses them.
#   interface    a name in a library's interface that this tree calls, as an oracle.
#   operational  a file that builds or drives an oracle, and so names the oracle's own files.
#                Exempt from the path rule only.
#   known        one spelling in one file, recorded when the gate began. A `known` line only
#                ever leaves: a spelling that is gone fails the gate until its line goes too,
#                and a new spelling is never added here.
#
# Every entry carries its reason. An entry with no reason is not an entry.
#
# format:  prefix|<prefix>|<whose identifiers it starts>
#          name|<identifier>|<whose routine it is>
#          path|<whose source it names>|<extended regex, runs to end of line>
#          macro|<what it is>|<extended regex, runs to end of line>
#          format|<identifier>|<the document that names it>
#          interface|<identifier>|<the interface, and what calls it>
#          operational|<file>|<the oracle it builds or drives>
#          known|<file>|<spelling>|<why it stands>
